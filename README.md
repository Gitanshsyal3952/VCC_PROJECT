This project is about building a small API using Python and Google Cloud Functions that provides real-time weather and stock market data. The main goal was to learn how to use cloud services to host code and get live information using external APIs.

We started by writing a Python function that can take a request and return data from free APIs — one for weather and another for stock prices. The function was tested locally first to make sure it was working correctly. Then we used Google Cloud SDK (gcloud CLI) to deploy this code to Google Cloud.
